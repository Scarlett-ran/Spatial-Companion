# Scout Exploration | Reading Guide

This folder explains Scout's creative origin, product thesis, existing work, and validation plans. Start with [Before We Begin](./00_Before_We_Begin.md), then use the [Exploration Overview](./00_Exploration_Overview.md) to understand the current status. The longer-term development path is in the top-level [Product Roadmap](../00_Product_Roadmap.md).

## Reading order and document responsibilities

The sequence is: **relationship premise → project overview → user problem → product thesis → behavior rules → existing work → assumptions and metrics → stage decisions → browser execution guide.** File numbers indicate the reading order, not research levels or development stages.

| File | Main question | Responsibility |
|---|---|---|
| [Before We Begin](./00_Before_We_Begin.md) | Why should Baobao be a companion? | Personal creative origin and intended relationship; not user research evidence. |
| [00_Exploration Overview](./00_Exploration_Overview.md) | What is the project, and where is it now? | Summary of the thesis, existing work, current task, and stage scope. |
| [01_Problem Statement](./01_Problem_Statement.md) | Who might need this connection? | Real circumstances, three candidate segments, alternatives, and exploration conditions. |
| [02_Product Thesis and Validation Framework](./02_Product_Thesis_and_Validation_Framework.md) | What relationship are we exploring, and how will value be assessed? | Core expression, value levels, research sequence, Now / Next / Later / Future, and the long-term world concept. |
| [03_Interaction Experience Specification](./03_Interaction_Experience_Specification.md) | How can a few behaviors express autonomy? | States, invitations and responses, no-interaction branches, low disruption, and ending rules. |
| [04_Concept Demo](./04_Concept_Demo.md) | How do the existing video and planned browser prototype work together? | Vision + Logic responsibilities, coverage, and evidence boundaries. |
| [05_Assumption Map](./05_Assumption_Map.md) | Which judgments need which evidence? | Assumption IDs, core metrics, observation methods, applicable stages, and interpretation. |
| [06_Next-Phase Decisions](./06_Next_Phase_Decisions.md) | How do we advance browser work, and when do we request a device? | Preparation, completion criteria, rationale for device access, and decision branches. |
| [07_Browser Demo Validation Goal](./07_Browser_Demo_Validation_Goal.md) | What will the current prototype build and test? | Minimum scope, behavior-to-capability mappings, observations, validation boundaries, and deliverables. |
