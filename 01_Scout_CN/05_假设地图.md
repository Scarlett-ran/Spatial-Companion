# 探索阶段 05 — 假设地图

本章统一管理假设、指标与证据。D 为设计假设，U 为用户／产品假设，T 为技术假设。目前尚无外部用户或真机验证结果；Browser 阶段先由本人自测 T3，有参与者时再收集 D3、D4 及需求反馈。

## 1. 假设与验证安排

| 编号 | 待验证判断 | 所需证据／影响 |
|---|---|---|
| D3 | 用户能理解行为因果及互动结束。 | Browser 中的解释、预期与提示需求；影响本轮行为模型能否继续。 |
| T3 | 本轮选定状态能由规则驱动并连贯运行。 | 正常分支、输入冲突、退出及恢复可重复运行；具体状态见 03，真机稳定性另测。 |
| D4 | 少量自主活动让用户初步感到豹豹有自己的生活。 | 无操作时的行为归因；本轮辅助诊断，持续可信度后测。 |
| U2a | 年轻用户愿意尝试自主空间伙伴。 | 具体情境、替代方式及尝试／拒绝原因；不推导设备采用。 |
| U5 | 养宠限制、角色情感连接和环境陪伴偏好比年龄更能解释需求差异。 | 早期记录经历与细分重叠；本轮不比较出最佳人群，解释力比较需后续样本。 |

本轮优先人群及需求问题见 [01_问题陈述](./01_问题陈述.md)。以下假设按相应研究条件正式判断，当前反馈仅作为线索。

| 编号 | 待验证判断 | 所需证据／影响 |
|---|---|---|
| D1 | 位置、尺度、可接近身体与空间一致回应形成“就在这里”的感觉。 | 真机中分别检查位置、尺度、深度与接近；影响空间呈现方案。 |
| T1 | 角色能以合理尺度保持稳定空间位置。 | 放置、绕看、接近和重新定位记录；各能力分别判断。 |
| D2 | 无物理触觉时，视觉与行为回应仍能产生可信主观接触。 | 真机同步、延迟、无回应对照及动作归因；接触失败不自动否定非接触共处。 |
| T2 | 可用输入能识别邀请、接近、接触与撤回，并及时反馈。 | 权限、精度、误触发／漏触发及延迟；眼动、头部、手部和控制器代理分别记录。 |
| U1 | 无照料义务的共处、察觉与回应能产生陪伴价值。 | 具体共处体验、保留和关闭理由，区分装饰、娱乐与新鲜感。 |
| U1a | 没有主动互动时，存在本身仍有价值。 | 非互动任务中主动保留／隐藏及有无角色的体验差异。 |
| U3 | 新鲜感消退后，仍愿再次见到同一只豹豹。 | 多次相遇中的关系感、自发返回与关闭理由；低频使用不直接判失败。 |
| U4 | 跨应用共存比独立应用更有价值。 | 实际可用形态中的任务对照、打扰与取舍。 |
| U6 | 相比二维角色，空间呈现增加有意义的陪伴价值。 | 角色、行为与时长相近的二维／空间对照；与空间存在感分别判断。 |
| U2b | 陪伴价值足以支持实际设备条件与重复使用。 | 获取、佩戴、启动与重复选择；区分已有设备与专门为豹豹佩戴。承接设备代价判断。 |
| T4 | 跨应用共存与跨时段状态延续在平台上可行。 | 共存、保存和恢复分别核查；保存状态不证明跨应用可见。 |

## 2. 指标与证据解释

| 指标 | 对应假设 | 观察重点与适用条件 |
|---|---|---|
| M1 — 交互可理解性 | D3、T3 | 行为解释、预期、结束理解与提示需求；Browser 主要指标。 |
| M2 — 感知自主性 | D4 | 无操作时归因为自身活动、等待、循环、随机或故障；辅助诊断。 |
| M3 — 空间存在感 | D1、T1 | 位置、尺度、深度与接近判断；真机验证。 |
| M4 — 接触可信度 | D2、T2 | 接近、接触、穿透与撤回的感受及归因；独立真机实验。 |
| M5 — 非互动共处价值 | U1a | 非互动时主动保留／隐藏及理由；共处阶段正式判断。 |
| M6 — 陪伴价值 | U1、U3、U6 | 共处与重逢体验；短时、多次相遇、媒介差异分别报告。 |
| M7 — 低打扰接受度 | U1、行为约束 | 注意力压力、被要求回应及关闭理由；Browser 检查行为压力，真机再查遮挡等实际打扰。 |

这些是项目指标，不是已验证量表。自主性不独立决定是否申请真机；若已有反馈伴随因果误解或内疚负担，也须计入 M1／M7 的问题。

## 3. 研究轮次与依赖

| 轮次 | 主要验证 | 进入关系 |
|---|---|---|
| RQ1 — Browser | 先自测 T3；有参与者时收集 D3、D4 与 M7 反馈。 | 当前独立制作阶段；需求访谈按可用条件安排。 |
| RQ2 — 空间存在 | D1、T1／M3 | Demo 较成熟后申请支持；取得设备并核查能力后进入真机阶段。 |
| RQ3 — 接触 | D2、T2／M4 | 有可用输入后单独选择开展，不是共处的必经步骤。 |
| RQ4a — 共处 | U1a、U1／M5–M7；适当对照研究 U6 | 空间存在有积极信号后可开展非接触共处。 |
| RQ4b — 多次相遇 | U3、D4／M2、M6 | 短时共处有价值线索后检查持续性。 |
| RQ5 — 采用与形态 | U2b、U4 | 关系价值有积极信号后，在实际设备与可用形态中判断。 |
| 长期世界 | U3、U4、T4 | 前述证据支持继续投入时再安排。 |

每轮记录假设／指标、版本与运行条件、实际样本、任务与分支、提示、事件与原话、支持／反驳／未决及限制。自测记录不算用户样本；没有参与者反馈时，用户假设保持未验证，仍可按 Demo 成熟度申请真机支持。采集安排见 [07_Browser_Demo验证目标](./07_Browser_Demo验证目标.md)，两个阶段的衔接见 [06_下一阶段决策](./06_下一阶段决策.md)。是否继续个人修正，由本人结合问题价值与可用时间判断。
