# 01 — 探索阶段（Scout）

Scout 围绕同一个主问题展开：**真实养宠受到时间、精力、金钱、居住条件与长期责任的限制，而二维虚拟宠物缺少与用户共享空间的实体感。空间宠物能否回应这两项不足？** 低打扰是设计约束，“豹豹”是已确定角色；陪伴效果、年轻用户接受度和技术可行性仍是假设。

先读顶层的 [`产品规划路线图`](../00_产品规划路线图.md) 了解五阶段路径，再读 [`00_探索阶段单页概览.md`](./00_探索阶段单页概览.md) 查看当前阶段的证据与边界。

| 文件 | 目的 | 何时阅读 |
|---|---|---|
| [01_问题陈述](./01_问题陈述.md) | 展开 problem、why now、why us。 | 需要理解养宠门槛、二维替代方案的不足，以及空间宠物为何值得探索时。 |
| [02_假设地图](./02_假设地图.md) | 区分事实、已定设计与设计、用户、技术假设。 | 需要检查哪些判断缺少证据、先验证什么时。 |
| [03_概念Demo](./03_概念Demo.md) | 展示当前概念。 | 需要观看 20 秒视频、了解它表达哪些假设时。 |
| [04_下一阶段决策](./04_下一阶段决策.md) | 把核心假设转化为验证目标和方法。 | 需要决定下一步应收集哪些证据，以及是否有必要开展用户研究时。 |
| [05_交互体验规格](./05_交互体验规格.md) | 说明候选方案如何回应问题。 | 需要展开空间行为、五个状态、安全暂停、自然退出和无照料义务的规则时。 |

阅读关系是：单页统领全局，问题陈述解释动机，假设地图标出证据缺口，Demo 展示设计意图，下一阶段决策安排验证，交互体验规格定义候选方案的具体行为。当前成果与验证状态以单页为准。
