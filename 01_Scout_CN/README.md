# Scout 探索阶段｜阅读入口

本文件夹说明 Scout 的创作缘起、产品主张、现有成果与验证安排。首次阅读可先看[写在前面](./00_写在前面.md)，再通过[单页概览](./00_探索阶段单页概览.md) 了解当前状态；长期研发路径见上层[产品规划路线图](../00_产品规划路线图.md)。

## 阅读顺序与文档分工

阅读逻辑是：**关系立场 → 项目概览 → 用户问题 → 产品主张 → 行为规则 → 当前成果 → 假设与指标 → 阶段决策 → Browser 执行说明。** 文件编号表示正文阅读顺序，不表示研究层级或研发阶段。
