# 豹豹 Scout 阅读入口

这里是中文 Scout 主文档目录。豹豹是一个有自己生活节奏、不说话的虚拟动物伙伴，最终面向轻便 MR 眼镜，探索与用户共同生活在真实空间中的体验及逐渐形成的 emotional bond。

## 当前状态与阅读顺序

目前已使用 Codex 制作 Functional Web Prototype（FWP）。0.1.0 已有本地可运行版本和静态发布包，公开部署和用户试用尚未完成。已有角色参考图、关键帧、概念视频和五份概念访谈记录；这些不等于三维模型、骨骼、可运行动画或实际使用证据。设备未定。

| 顺序 | 文档 | 回答的问题 |
|---|---|---|
| 1 | [产品定义](01-product-definition.md) | 豹豹是什么，为谁、在什么情境下提供什么体验？ |
| 2 | [证据与决策](02-evidence-and-decisions.md) | 有哪些研究线索与反例，为什么作这些选择，还不知道什么？ |
| 3 | [体验与原型](03-experience-and-prototype.md) | 生活、互动、时间与空间边界是什么，FWP与眼镜原型怎样区分？ |
| 4 | [验证与下一步](04-validation-and-next-steps.md) | 已交付什么、还需做什么、希望了解什么、反馈怎样影响决定？ |

工作顺序：**制作FWP → 用户使用与调整 → 制作眼镜原型 → 空间体验试用。**

作为本次整理采用的Scout工作定义：让方向、依据与未知、最小体验和下一决定足够清楚，能够继续探索；不是要求先证明长期关系，也不是恢复旧路线图的阶段门槛。FWP核心体验正常运行、经过用户使用并处理主要困惑后，可以推进眼镜原型。
