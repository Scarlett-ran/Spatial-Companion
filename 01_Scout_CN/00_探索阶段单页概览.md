# 豹豹Baobao, an autonomous spatial companion
> 「豹豹」探索一个自主空间伙伴，能否通过安静共处、相互察觉与轻量互动，在无需照料义务时形成有意义的陪伴。

**当前状态：** 问题探索（TRL 1–2），已有概念表达；当前工作方向为 Browser 交互逻辑原型，尚未完成构建与用户测试。

## 1. 目标用户是谁？产品是什么？
本产品从养宠限制出发，关注用户与角色建立连接、获得低压力陪伴的可能性。保留 Z 世代及之后的年轻用户设定，并增加养宠受限、角色情感连接、环境陪伴偏好三类候选细分。它们可能重叠，需求强度、具体场景及哪类群体更有潜力均未验证，见 [01_问题陈述](./01_问题陈述.md)。

豹豹是一只勇敢的、可以独立生活的竖琴海豹幼崽，与用户各自生活、偶尔相遇。自主活动和自然回应是候选机制；低打扰、无喂养维护、无签到、无惩罚和无照料债务是设计约束。关系主张见 [02_产品主张与验证框架](./02_产品主张与验证框架.md)。

## 2. 当前已有成果与用途

| 材料或工作 | 状态 | 用途与边界 |
|---|---|---|
| 产品文档与角色视觉参考 | 已有 | — |
| 约 20 秒概念视频 | 已有 | 表达愿景、氛围、空间意图与预期互动过程。 |
| Browser 原型与用户测试 | 待开展 | 拟说明状态、时序、因果和输入输出，并检查行为理解与初步自主性。 |
| 目标平台核查与真机原型 | 尚未完成 | — |

现有视频与待建 Browser 将组成 **Vision + Logic** 的研发沟通材料，见 [04_概念Demo](./04_概念Demo.md)。空间体验起点来自个人 Apple Vision Pro 观察，目标产品平台为歌尔自有 VR；不能由前者推定后者能力，项目尚无设备或工程支持承诺。

## 3. 现在、下一步与长期范围

| 方向 | 主要任务 |
|---|---|
| NOW — Browser | 检查行为因果、状态与时序、自然结束和初步自主性，明确输入输出并支持设备资源申请。 |
| NEXT — 首轮 XR | 核查平台，优先验证空间存在、稳定尺度与位置，再单独检查真实输入和主观接触。 |
| LATER — 陪伴与采用 | 分轮验证非互动共处、低打扰、关系连续性、自发返回及实际设备选择。 |
| FUTURE — Baobao World | 探索“豹豹的世界 ↔ 豹豹来访 ↔ 用户数字世界”；当前不实现完整世界或跨应用运行。 |

每轮聚焦一个主要风险，阶段方向不表示已经完成或获批。指标与证据边界以 [05_假设地图](./05_假设地图.md) 为准。

## 4. Browser 阶段希望取得什么结果

1. 明确待验证的用户问题、候选人群与产品假设。
2. 独立完成可重复演示的 Browser Demo，并检查状态、输入、退出和异常恢复。
3. 有条件时收集行为理解、初步自主性和需求反馈；没有参与者时如实保留为未验证。
4. 形成演示、行为说明、已知问题和最小设备需求，用于申请真机与外部支持。
