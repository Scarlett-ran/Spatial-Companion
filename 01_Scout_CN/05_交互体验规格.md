# 探索阶段 05 — 交互体验规格

## 1. 核心体验

| 问题或约束 | 候选方案的回应 | 对应假设或边界 |
|---|---|---|
| 真实养宠的条件限制与责任负担 | 使用已确定的虚拟角色豹豹；无喂养、无签到、无惩罚、无长期照料义务。 | U1、U2：减少照料要求是否有价值、用户是否接受，仍待验证；设备使用条件仍然存在。 |
| 二维宠物缺少空间实体感 | 保持合理身体尺度和相对稳定的位置，允许用户通过视角变化与靠近感知身体，再以连贯动作回应。 | D1、T1：空间呈现的体验优势和稳定性均待验证。 |
| 接近身体时的反馈关系 | 手部接近、接触与撤回分别对应可理解的身体回应，不配置物理触觉反馈。 | D2、T2：主观触碰感和输入、反馈的可行性均待验证。 |
| 低打扰设计约束 | 默认休息，互动由用户邀请，忽略不升级，结束后自然退出。 | 这是行为要求，不是新的主问题或已成立的陪伴效果。 |

豹豹以安静共存为默认状态。它可以察觉用户，但不会持续索取注意力；只有在用户通过注视、靠近或触碰发出邀请后，互动才会进一步发展。用户停止互动后，豹豹应自然退出并回到安静状态。

注视、靠近和触碰在此描述体验意图；目标设备是否提供对应输入、可用精度与权限条件仍需验证，不预设可直接读取目光数据。

体验节奏为：

`在附近休息 → 察觉 → 回应 → 可选靠近 → 退出互动 → 在附近休息`

## 2. 五个体验状态与一个安全状态

| 状态 | 体验目的 | 进入条件 | 允许行为 | 退出方式 |
|---|---|---|---|---|
| 在附近休息 | 建立无需操作的共同存在。 | 会话开始、互动结束或长时间没有用户邀请。 | 呼吸、姿态微调、偶尔观察环境。 | 可以短暂进入察觉；否则继续休息。 |
| 察觉 | 表达有限感知，不强迫用户回应。 | 用户持续注视或主动靠近；无明确邀请时，仅允许在单次会话中首次检测到用户进入预设接近范围时触发一次。 | 转头、睁眼、轻微抬头或短暂观察。 | 用户继续邀请则进入回应；没有邀请则回到休息。 |
| 回应 | 确认用户的有意行为。 | 用户伸手、轻触或继续靠近。 | 观察手部、嗅闻、蹭手或接受短暂抚摸。 | 用户继续邀请时可短暂维持；否则进入退出互动。 |
| 可选靠近 | 提供更明确但不强制的互动时刻。 | 用户明确邀请，且空间与输入条件可靠。 | 小幅调整位置，保持安全距离且不遮挡主要内容。 | 被忽略时停止靠近并进入退出互动。 |
| 退出互动 | 清楚结束一次互动。 | 用户移开视线、撤回手或恢复主要活动。 | 减少动作、移开关注并重新安定。 | 回到在附近休息。 |
| 安全暂停 | 避免错误、突兀或不安全的空间行为。 | 追踪丢失、输入不确定、空间不足或应用中断。 | 停止移动与互动；无法可靠维持空间位置时隐藏角色，应用中断时不要求继续显示。 | 环境重新可靠后回到休息；否则保持暂停。 |

## 3. 手部动作与宠物回应

| 用户动作 | 豹豹的预期回应 | 不允许的回应 |
|---|---|---|
| 手缓慢靠近 | 留在原处，用眼睛追踪手，轻微歪头；确认安全后嗅闻一次。 | 主动扑向手、瞬间靠近或连续吸引注意。 |
| 轻触额头或脸颊 | 放松表情，小幅闭眼或轻轻蹭向手指。 | 夸张弹跳、强制进入长时间互动。 |
| 短暂轻柔抚摸 | 保持稳定姿态，以呼吸、表情和细小身体动作回应。 | 抓住用户、阻止手离开或要求重复操作。 |
| 快速伸手或突然靠近 | 轻微后缩或暂停，保持安全距离。 | 攻击、惩罚用户或持续表现负面情绪。 |
| 撤回手 | 停止回应，短暂注视后逐渐回到休息。 | 追赶、反复靠近或用声音要求继续。 |

手部接触只代表系统未来可能通过视觉、动画和声音反馈模拟接触，不暗示设备能够提供真实触觉。

## 4. 低打扰规则

1. 安静共存是有效状态，不是等待用户操作的空白状态。
2. 每个会话中，在没有用户邀请的情况下，豹豹最多只能从休息进入一次察觉，且不能继续升级行为强度。
3. 豹豹不能频繁进入中央视野、遮挡主要内容或重复发出声音。
4. 用户忽略豹豹时，不得出现惩罚、负面情绪、进度损失或更强提醒。
5. 不要求持续手势或持续对话；无照料义务的具体规则见下节。
6. 不持续监听环境，不推断用户情绪，也不读取其他应用内容。

## 5. 无照料义务规则

| 明确约束 | 行为要求 |
|---|---|
| 无喂养 | 不设置饥饿、口渴或必须补充的资源条，不用喂食维持健康、存活或亲近状态。 |
| 无签到 | 不设置每日任务、连续登录奖励或必须回访的周期要求。 |
| 无惩罚 | 忽略、离开或关闭不会引发衰弱、生病、死亡、关系降级、进度损失或内疚式提醒。 |
| 无长期照料义务 | 不安排清洁、医疗、成长养成等必须完成的维护任务；不因离线积累待办，返回时无需补做照料。 |

用户可以随时结束互动、隐藏豹豹或关闭体验，不需要告别操作或承诺下次回来。豹豹的休息与恢复不以用户照料为条件；后续若保存状态，也不得引入离线消耗或照料债务。这些要求直接回应真实养宠中的责任负担，其陪伴价值仍按 U1 验证。

## 6. 自然退出规则

- 用户撤回手、移开视线或恢复主要活动，都视为结束邀请。
- 豹豹应在一次简短反馈后降低动作强度，不再次追问或靠近。
- 退出过程应从回应过渡到安定姿态，避免突然冻结或循环播放告别动作。
- 退出后回到附近休息，位置与尺度保持连续。
- 任何输入或追踪不确定都优先进入安全暂停，而不是猜测用户意图。

## 7. 当前实现边界

概念 Demo 已经呈现了休息、察觉、触碰回应和自然退出的视觉意图，但没有实现上述状态逻辑。若进入技术验证阶段，浏览器模拟仅用于检查状态、触发与反馈是否连贯；真实注视输入、手部追踪、空间定位、遮挡和跨应用共存仍需等待 XR 真机验证。
