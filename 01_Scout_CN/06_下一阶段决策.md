# 探索阶段 06 — 下一阶段决策

Browser 交互逻辑原型是当前推进方向。本文说明如何启动这一轮、如何判断结果，以及什么证据足以支持申请真实设备；具体工作内容见 [07_Browser_Demo验证目标](./07_Browser_Demo验证目标.md)。

## 1. 当前探索的成功标准

当前希望判断：**豹豹的行为模型是否足够可理解、连贯，并具有初步可信的自主性，值得在真实设备上继续验证空间存在。** 同时应形成具体的行为与能力参考，让研发可以判断下一步所需条件。

这一定义不要求当前证明长期陪伴、购买意愿、持续使用或整个产品已经成立。需要区分两个节点：Scout 文档与范围准备完成，意味着可以安排 Browser 验证；Browser 实际测试完成，才可能对行为模型作出结论。当前仍处于前一节点的准备工作，没有 Browser 测试结果。

## 2. 启动 Browser 前需补齐什么

| 项目 | 现有依据 | 待确认内容 |
|---|---|---|
| 问题与指标 | 主问题为行为理解与连贯性；辅助观察自主性和注意力负担。 | 按 05、07 选定具体观察项和本轮分支。 |
| 原型范围 | 少量自主活动、有互动与无互动、代理输入、自然退出。 | 活动选择、输入映射、反馈时长、构建工作量和检查安排。 |
| 研究计划 | 三类候选用户细分及证据边界已定义。 | 样本数量、招募条件、任务、时长、观看顺序和记录方式。 |
| 判断标准 | 研究结果和研发参考分别交付。 | 测试前确定可观察的通过／修改／停止阈值，保留相反反馈和未决结果。 |
| 资源与责任 | Browser 是当前方向。 | Mentor 的范围与投入确认、执行负责人、时间安排、工作量上限及评审日期。 |

文档方向已明确，不表示内部资源已经获批。项目尚无设备或工程支持承诺；上述未定信息不得填成既定事实。

## 3. Browser 完成后，如何判断是否值得继续

| 判断维度 | 应提交的证据 | 判断重点 |
|---|---|---|
| 行为可理解且连贯 | 按分支整理的用户解释、误解、所需提示、状态与时序记录。 | 用户能理解邀请后的回应与自然结束；问题可以区分为实现故障或行为设计问题。 |
| 初步自主性与低打扰 | 无操作时的描述、行为归因、注意力压力及退出反馈。 | 不把随机、不响应或内疚误记为自主性；明确仍需调整的表现。 |
| 研发参考可用 | Video + Browser、状态与分支、输入输出、时序、恢复说明及能力映射。 | 研发能据此讨论具体输入、权限、运行条件和最小试验，而不只是看到一个角色概念。 |
| 剩余风险清晰 | 已检查、未解决及 Browser 无法验证的问题清单。 | 说明哪些问题还能在 Browser 修正，哪些必须依赖真实设备。 |

这些是完成标准的维度，不是已经通过的结论；数值阈值与可接受问题范围需在测试前结合样本和任务确定。概念喜欢程度、再次点击或口头共处意愿作为辅助信息，不替代主要判断，也不单独决定是否进入真机。

## 4. 为什么下一组问题需要真实设备

申请逻辑应由证据支持：先报告本轮减少了哪些可在 Browser 检查的风险，再说明剩余核心问题为何无法通过代理输入取得有效证据。当前尚未测试，不能提前宣称风险已经降低。

真实空间存在、身体尺度、深度、真实注视和手部输入、主观接触、空间共处与目标运行稳定性，都需要相应设备条件。**设备访问是取得下一组空间证据的必要条件；申请目的是回答这些问题，而不只是制作更精致的 Demo。** 获得设备后仍需核查能力、权限和原型条件。

首轮设备请求优先服务 RQ2：确认目标平台、建立稳定尺度与位置、检查接近和绕看时的空间存在。真实接触作为后续单独实验，不要求首轮同时具备完整眼动、手部输入和跨应用能力。平台信息可以提前沟通，跨应用实现仍后置。

申请材料需包含最小研究问题、所需设备与能力、权限和部署要求、工程协作角色、工作量与周期、待观察证据及停止条件；具体值待与研发确认。Browser 不能验证的全部问题，是后续研究边界，不是一次性申请的全部开发范围。

## 5. 决策结果与记录

| 结果 | 后续动作 | 结论边界 |
|---|---|---|
| Go — 申请限定真机资源 | 行为模型与参考达到预设条件，提出有范围的设备访问和工程支持请求。 | 不自动获批，不代表空间、接触或产品价值已成立。 |
| Iterate — 修正 Browser | 针对可定位的行为误解、时序或自主性问题修改并复查。 | 不因缺少真机证据而持续添加 Browser 无法验证的功能。 |
| Redirect — 调整方法或机制 | 根据新证据记录需要改变的问题、输入或验证条件。 | Browser 的双重用途仍保留；调整某个试验不等于取消整个方向。 |
| Stop / Hold — 停止或暂缓投入 | 明确资源、行为模型或研究条件方面的原因。 | 作用于当前投入或机制，不等于所有空间伙伴假设被证伪。 |
