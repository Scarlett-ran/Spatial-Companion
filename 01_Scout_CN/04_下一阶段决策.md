# 探索阶段 04 — 下一阶段决策

以下是项目需要逐步回答的体验与用户验证目标，不代表它们都由当前 Browser Demo 完成。Browser 阶段只检查交互规则与因果关系的可读性，并为 U1、U2 收集早期方向性信号；D2 必须等待真机交互，仍是进入真机后的首要体验验证目标。

## O1 — 无物理触觉反馈能否形成主观触碰感

| 项目 | 内容 |
|---|---|
| 假设 | D2：视觉与行为反馈能在没有物理触觉反馈时形成可信的主观触碰感。 |
| 要观察的证据 | 体验者是否自发描述“碰到”豹豹，能否把回应归因于自己的手部动作；何时感到穿透、延迟或只是触发动画；反馈有无或时机变化是否改变感受。 |
| 最低成本方法 | 真机仅制作额头一个接触区域和一个回应动作，对比有同步回应与无回应条件，记录接近、接触、撤手过程及体验后的中性提问。无设备时只审阅反馈时序，不把视频观看或鼠标操作当作触碰验证。 |
| 表述边界 | 结果最多支持特定条件下的主观触碰感，不代表物理触觉，也不能单独证明陪伴价值。追踪与延迟问题需与体验判断分别记录。 |

## O2 — 无长期照料义务的空间宠物是否有价值

| 项目 | 内容 |
|---|---|
| 假设 | U1：即使无喂养、无签到、无惩罚、无长期照料义务，安静共存与轻量回应仍能带来陪伴价值。 |
| 要观察的证据 | 体验者如何区分陪伴与装饰，在哪些具体情境中愿意保留或关闭豹豹；是否理解忽略和离开不会导致损失；无照料机制是否减轻负担，或反而削弱关系感。 |
| 最低成本方法 | 若决定开展用研，先用现有 Demo 加一张明确写出四项无照料规则的情境卡做少量概念访谈，以中性提问记录使用理由、拒绝理由和负担理解；需要检查实际感受时，再让最小原型伴随一项短任务出现，允许随时忽略或关闭。 |
| 表述边界 | 概念访谈只提供预期价值与规则理解的线索；短时体验也不能证明长期陪伴效果、新鲜感消退后的价值或心理健康改善。 |

## O3 — 年轻用户是否愿意接受这种方案

| 项目 | 内容 |
|---|---|
| 假设 | U2：Z 世代及之后的年轻用户愿意接受空间宠物及其设备使用条件。 |
| 要观察的证据 | 实际养宠限制、当前采用的替代方式、愿意尝试或拒绝的具体原因，以及设备可获得性和佩戴条件对选择的影响；区分喜欢豹豹与愿意使用产品。 |
| 最低成本方法 | 若决定开展用研，可与 O2 合并为一次少量访谈，但应单独记录 U2：先询问实际生活情境与替代行为，再展示概念并说明设备条件。若暂不研究，只整理待问问题，不形成接受度结论。 |
| 表述边界 | 少量访谈只提供方向性线索；口头兴趣不等于采用、购买或持续使用，不能代表整代年轻用户。 |
