# Spatial Companion 角色设计：豹豹

## 角色设计说明

- **动物原型**：幼年竖琴海豹，略作圆润化与角色化处理。
- **身体比例和整体轮廓**：头部约占全长 38%，圆头、短颈、低重心的椭圆水滴形身体；自然趴坐时完整展示两只前鳍、成对后鳍，以及后鳍之间极短的尾突。
- **头部、眼睛、耳朵、四肢和尾巴**：深午夜蓝圆杏形眼睛，眼白几乎不可见；小而柔软的三角鼻；灰炭色心形口鼻区；左右各六根清晰胡须；没有外露耳廓，仅有头侧两个浅小耳孔；前鳍短厚，后鳍扁圆且对称，尾突极短。
- **毛发颜色、纹理和材质**：主体为温暖象牙白，额头保持无图案的连续象牙白短绒；全身是短密天鹅绒质感，带非常克制的珠光但不发光；鼻口区与鳍端使用柔和石墨灰过渡。
- **性格关键词**：勇敢、自立、温暖、安静、轻柔、慢热、略带好奇、信任后主动亲近。
- **最容易识别的三个视觉特征**：午夜蓝圆杏眼；灰炭色心形口鼻区；温暖象牙白水滴形身体配石墨灰鳍尖。
- **绝对不能改变的特征**：额头无图案；眼睛颜色与形状；象牙白—石墨灰—深午夜蓝配色；头身比例；无外露耳廓；两只前鳍、两只后鳍和极短尾突；短密绒毛与统一三维渲染质感。
- **应避免的元素**：任何额头图案、兔耳或猫耳、四足兽爪、长尾、翅膀、角、多余肢体或尾巴、服装与配饰、项圈、发光特效、随机斑点、夸张动漫眼、塑料玩具感、复杂场景、文字、标志、水印，以及对参考图中具体画面的直接复制。

## 参考图使用原则

六张输入图片均只作为视觉参考，用于理解幼年海豹的自然比例、短密白绒、眼鼻湿润质感、胡须结构和安静姿态；它们不是编辑目标，也不应复制其中的具体构图、环境、文字或水印。

## 角色生活与关系原则

豹豹是一只可以照顾自己的勇敢小海豹，有自己的想法、兴趣、活动和世界。用户与豹豹各自生活、偶尔相遇；它不依赖用户喂养或维持生存。用户进入时，它可以已经在休息、观察或自己玩耍，不强制立即关注用户并等待操作。

设计原则：**Baobao should never look like he exists only because the user opened the product.** 无照料义务允许未来保留关系痕迹，但不能产生关系衰减或回访压力。当前以少量预设活动表现独立生活；狩猎、探索、带回物品及自己的世界属于长期愿景，不是现有能力或当前 MVP 要求。

本补充定义行为与世界观，沿用已有视觉特征。产品定位、三级验证与范围详见[产品主张与验证框架](../01_Scout_CN/02_产品主张与验证框架.md)。
